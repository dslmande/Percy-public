# Percy – öffentliche Seiten

Percy ist ein kleiner Desktop-Synthesizer mit Touch-Tastatur nach dem Vorbild des EDP Wasp (DIYsynth / dsl-man.de).

## 3D-Ansicht

**https://dslmande.github.io/Percy-public/**

Interaktive 3D-Ansicht von Gehäuse, Hauptplatine, Frontplatte und Rückwand mit Montage in 14 Schritten,
Explosionsansicht, Schnitten und Abstandsmessung (three.js, läuft im Browser).

Stand 27.10.2026: Gehäuse Rev0.7-FDM (Eigendruck PETG-CF, 13 Einschmelzmuttern, Hauptplatine an neun Bolzen fest), Rückwand Rev0.4, Hauptplatine Rev0.8, Frontplatte Rev0.7.
